Практическое задание 04 — Служба определения местоположения

Открытие:
1. Распакуйте архив.
2. В Android Studio выберите Open и укажите папку LocationService.
3. Дождитесь Gradle Sync и запустите на устройстве/эмуляторе с включённой геолокацией.

Перед сдачей:
- В MainActivity.java замените HOME_LATITUDE и HOME_LONGITUDE на координаты своего дома.
- Интерфейс реализован в app/src/main/res/layout/activity_main.xml.
- Разрешения находятся в app/src/main/AndroidManifest.xml.
- Адрес определяется через Android Geocoder. Это не API Яндекса; для строгого выполнения пункта «Отлично» с API Яндекса нужно подключить Яндекс Геокодер и использовать собственный API-ключ.
- Проверьте сборку в установленной версии Android Studio/Gradle.
